HealthySongs Live (web demo)

In VS Code: press Ctrl+Shift+B (with the "music" folder open).
Without VS Code: double-click start-live-demo.bat.

It opens http://localhost:8123/live.html. Allow the camera.
Works offline: the face model is in vendor/model. Needs Node.js (or Python).
Stop it with Ctrl+C in the terminal window.
